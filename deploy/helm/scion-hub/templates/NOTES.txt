 3. Authenticate the CLI
==============================================================================

{{- if eq .Values.auth.mode "dev" }}
{{- if .Values.auth.dev.token }}

    Dev token was set explicitly via values:

        export SCION_DEV_TOKEN={{ .Values.auth.dev.token }}
{{- else }}

    Dev token is auto-generated inside the pod. Retrieve it with:

        kubectl exec -n {{ .Release.Namespace }} deployment/{{ $fullname }} -- cat /home/scion/.scion/dev-token
        # then on the client:
        export SCION_DEV_TOKEN=<that-token>

    For a stable workflow, set `auth.dev.token` in values.yaml or your
    external secret.
{{- end }}
{{- else }}

    {{- range .Values.gateway.hostnames }}
        https://{{ . }}/auth/login
    {{- end }}

==============================================================================
 4. Register a Runtime Broker
==============================================================================

The Hub does not run agents itself. Connect a broker from outside the cluster
(your laptop, a Steam Deck, another K8s cluster) to provide execution capacity:

    # On the broker machine:
    export SCION_HUB_ENDPOINT={{ if .Values.gateway.hostnames }}https://{{ index .Values.gateway.hostnames 0 }}{{ else }}<set-this>{{ end }}
    scion broker register
    scion broker provide

See docs/hub-user/runtime-broker/ for the full flow.
